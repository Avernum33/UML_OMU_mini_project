# PlantUML Diagrams

These files are the source diagrams for the report.

## Files

- `01-use-case.puml` - high-level use case diagram.
- `02-class-initial.puml` - class diagram before design patterns.
- `03-sequence-browse-customize.puml` - sequence diagram for browsing and customizing an item.
- `04-sequence-place-order-payment.puml` - sequence diagram for placing and paying for an order.
- `05-sequence-admin-update.puml` - sequence diagram for admin product updates.
- `06-class-refined-patterns.puml` - refined class diagram with selected patterns.
- `07-sequence-observer-catalog-sync.puml` - Observer pattern sequence.
- `08-sequence-factory-product-creation.puml` - Factory Method pattern sequence.
- `09-sequence-singleton-catalog-access.puml` - Singleton pattern sequence.

## Rendering

Use a PlantUML plugin or CLI:

```bash
plantuml diagrams/plantuml/*.puml
```
